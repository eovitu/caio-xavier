# SaiDaReta

Site editorial de Caio Xavier. A abertura apresenta um estudo tridimensional de uma bolsa transversal. A rolagem revela o volume, a alça e o pesponto. A linha leva à história e aos bastidores.

## Desenvolvimento

Requisitos: Node.js 24 e npm.

```sh
npm ci
npm run dev
```

Abra http://localhost:3000. Antes de abrir um PR, execute `npm run lint`, `npm run typecheck` e `npm run build`.
