# SaiDaReta

Site editorial de Caio Xavier. Fotografias reais apresentam as peças, o processo e a rua. A experiência usa GSAP e Lenis, com navegação interna e alternativa de movimento reduzido.

## Desenvolvimento

Requisitos: Node.js 24 e npm.

```sh
npm ci
npm run dev
```

Abra http://localhost:3000. Antes de abrir um PR, execute `npm run lint`, `npm run typecheck` e `npm run build`.
